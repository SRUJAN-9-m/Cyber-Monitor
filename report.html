Executive Summary

Section 1

CyberMonitor is a single-file Python web application that gives beginners a practical, hands-on tool for understanding Windows Security Event logs without requiring a commercial SIEM platform like Splunk or Microsoft Sentinel.

The application is built entirely on open-source libraries, runs locally on any Windows, macOS, or Linux machine with Python installed, and requires no database, server configuration, or cloud account.

Key Design Principle: Zero-configuration startup. The app generates realistic mock data automatically, so a user can learn the interface before connecting any real log source.

Application Architecture

Section 4

Execution flow on each browser interaction (Streamlit reruns the entire script top-to-bottom on every widget change):

1 · Page Config + CSS
st.set_page_config() must be the first call. CSS is injected globally via st.markdown(unsafe_allow_html=True).
2 · Sidebar — File Uploader
The st.file_uploader widget is rendered. Its return value determines whether real or mock data is loaded.
3 · Data Load Pipeline
If a file is uploaded → load_uploaded_file() → normalise_columns(). Otherwise → generate_mock_data(). Result is a normalised DataFrame.
4 · Sidebar — Dynamic Filters
Multiselect widgets are populated with unique values from the loaded DataFrame. Filters are applied to produce filtered.
5 · Dashboard Render
KPI cards, charts, and tables all consume filtered. Any filter change triggers a full rerun, keeping all components in sync automatically.

Setup & Usage Guide

Section 6

Step 1 — Install dependencies

pip install -r requirements.txt

Step 2 — Launch the dashboard

python -m streamlit run app.py
Note: If streamlit is not recognised as a command, always use python -m streamlit. This happens when pip installs to user site-packages which may not be on your system PATH.

Step 3 — Export real Windows Security logs (PowerShell)

Get-WinEvent -LogName Security -MaxEvents 2000 |
  Select-Object TimeCreated, Id, LevelDisplayName, Message, ProviderName |
  Export-Csv -Path "$env:USERPROFILE\Desktop\security_events.csv" -NoTypeInformation

Step 4 — Upload to CyberMonitor

In the left sidebar, click Browse files and select your exported CSV. The dashboard reloads automatically with your real data.
